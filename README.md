# Project Suggestions based on your github profile
A simple project to get project suggestions with AI based on your github

---

# Used Tools
- TypeScript
- NodeJS
- Groq API
- GitHub Rest API

---

# How to use
1. Clone the repository
```
git clone https://github.com/kev1n999/github-suggestions
```
2. Install the dependencies
```
npm install
```
3. Create a .env
```
API_KEY= # Your GROQ(AI) API KEY
SERVER_PORT=4000
BASE_URL=https://api.github.com
```
4. Run
```
npm run dev
```
